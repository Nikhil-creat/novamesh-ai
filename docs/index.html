FAQ & deployment

Is this page the real backend?No. This is the showcase site. The full FastAPI backend is in backend/ and runs with Docker Compose.
Is my Groq key safe?It is kept in sessionStorage only, sent solely to api.groq.com, and cleared when the tab closes. Use a free-tier key and rotate it if shared.
How are critical actions protected?Consensus above 66%, deterministic policy checks, then explicit admin approval with an expiry window, all recorded in a hash-chained ledger.
